Reorganized code, to make it better readable. Divided all features in different classes.

    - Buttons.js: Code to design and operate the avaiable buttons.

    - Editor.js: Code that allows user to edit the graph, with other features like display the coordinates when hovered over a selected vertice

    - Graph.js: Code that allows the engine to store vertices and edges. Editor allows user to edit, and this class stores the changes.

    - Main.js: Is where all the algorithms can be tested and implemented without it affecting the editor code.
